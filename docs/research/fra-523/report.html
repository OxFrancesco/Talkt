Talkt · On-device speech recognition

Choose Parakeet v3
for the Fold 8.

Parakeet TDT 0.6B v3 INT8 had the lowest English and Italian word error rates of four tested models. It also decoded the sample fastest at the median, in 0.60 seconds.

The cost is memory. Peak native process RSS reached 1.48 GiB, and model loading took 2.31 seconds. Keep a smaller option for phones with less available memory.

WER is word error rate, so lower is better. Italian had 13 word errors with Parakeet versus 168 with tiny over 486 reference words. This is a 92.3% relative reduction on this sample.

What this means for Talkt

Use Parakeet as the Fold candidate. It covers all six languages Talkt exposes and works through the existing Sherpa runtime. The selected model files total 670.5 MB. Warm the model asynchronously and preserve the private recognition process and failure handling.

Whisper base is the smaller-device candidate at 160.6 MB of model files. It improves accuracy over tiny while keeping median warm decoding below one second here. Its Italian errors remain much higher than Parakeet's.

Parakeet and small returned empty text for digital silence. Tiny and base produced text on both passes when called directly. Keep Talkt's speech detection even when changing the model.

Measured selection, with clear limits

The native benchmark ran on the USB-connected Fold 8. It used the exact native libraries bundled in Talkt, verified by SHA-256. Model selection is complete. Talkt integration, personal dictation, noisy input and app lifecycle verification are still separate work.

No APK, Talkt settings or production backend changed. Qwen3-ASR and Omnilingual were researched but not benchmarked. This report names the winner among the four tested models.

Method and test conditions

Samsung SM-F971B, SM8850, Android 17, Sherpa-ONNX 1.13.6, ARM64 CPU, two threads, automatic language detection. The FLEURS sample contains 448.94 seconds of speech, with clips from 4.32 to 19.38 seconds, plus five seconds of generated silence. Each language uses 20 distinct sentence IDs selected from the start of its test archive.

Accuracy uses the first pass; warm timing uses the second. Predictions matched between passes. WER lowercases and strips punctuation, retains accents and counts digit-versus-word differences. The sample is read speech, not a representative personal dictation test.

Models ran sequentially in the order shown. Battery temperature ranged from 33.9 to 36.5 degrees C with USB connected. No controlled cooldown was performed. Model load starts in a new process, with OS page-cache state uncontrolled. RSS is the native process, not whole-app memory. The benchmark bypasses microphone capture, Binder, UI and cloud fallback.
