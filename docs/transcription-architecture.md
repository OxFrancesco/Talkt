# Local-first transcription

Talkt records one canonical 16 kHz mono PCM WAV. A single `Transcriber` first hands that exact file to a private `:local_asr` process running Sherpa-ONNX Parakeet TDT 0.6B v3 INT8. If the runtime is unavailable, low on memory, over the 60-second local limit, killed, or fails inference, local-first mode uploads the same WAV to the existing Cloudflare endpoint for Gemini 3.5 Transcribe. On-device-only mode reports the local failure without uploading. Silence is terminal and is not uploaded.

The private process is deliberate: a native crash or OOM can kill local inference without killing the capture UI, leaving Gemini fallback reachable. The recognizer is lazy, serialized and uses two CPU threads with 128-dimensional features. It recognizes all six configured Talkt languages automatically; language preferences still go to cloud transcription, but do not force Parakeet's language. Parakeet does not return a detected-language code, so local transcripts leave that optional field empty.

Both cold transcription and warm-up require at least 1,792 MiB of available memory and no Android low-memory flag. This is an admission threshold based on the Fold benchmark, not a guarantee against native OOM. A resident recognizer is reused without reapplying the cold-load threshold. Memory trimming and destruction queue cleanup on the same serial dispatcher as inference so they cannot free the native recognizer during decoding. Capture prewarms it while the user speaks; consecutive dictations reuse the service for up to five idle minutes. Starting cloud-only capture releases the warm-up binding.

The APK bundles the four Parakeet files, 670.5 MB combined. `bun run models:download` fetches the pinned export and validates checksums; Android builds also validate the model before merging assets. Weights stay out of Git. Attribution and the CC BY 4.0 license ship in `assets/licenses/`. See [the Fold comparison](research/local-asr-models.md) for the selection evidence.

Recording ends on trailing silence, on 8 s without any speech, or at a 60 s hard cap, whichever comes first. Speech is judged against a rolling noise floor (quietest 250 ms buffer in the last 4 s, times 2.5), not a fixed level: a fixed 450 RMS threshold sat below the room noise on the Fold next to a laptop, so the silence timer never started and captures ran until the user gave up. A mic silenced by Android's concurrent-capture policy (another app owns the input) is reported as such instead of being uploaded.

The capture bubble owns recording and transcription only. It shows the transcript with the engine and wall-clock transcription time, then closes. In agent mode it hands the transcript to `AgentRunService`, a foreground `dataSync` service that runs the prompt and posts the answer as a notification, so a slow agent never holds the overlay open.

`GEMINI_API_KEY` exists only as a Cloudflare Worker secret. The APK contains the local model and native arm64 runtime, plus the existing Worker app token; it never contains a Gemini credential.

Arena synthesis used candidate 1 as the base because its cache-backed clip and process boundary make audio identity and crash recovery structural. It grafted candidate 2's 60-second local ceiling and verification matrix. It rejected Android `SpeechRecognizer` because that service owns a different microphone capture, a downloadable first-run model because it makes fresh installs cloud-first, and in-activity orchestration because it leaks fallback policy into UI code.
