Talkt cloud transcripts

Google Drive backup is replaced by private R2 storage and per-account SQLite full-text search. Local transcripts stay available offline. Cloud backup is opt-in, with a choice to include existing notes.

Search covers transcript text and agent replies, with word prefixes and accent-insensitive matching. Users can copy notes and delete cloud copies. This is keyword search, without AI-generated answers.

Storage behavior

The verified Clerk account selects its own Durable Object and R2 prefix. Repeated uploads reuse the transcript UUID. Pending R2 operations retry through durable alarms. Cloud deletion removes search results and prevents later retries from recreating that UUID.

Deleting local notes keeps their cloud copies. Turning backup off retains existing cloud copies. Cloud deletion keeps the phone's local copy. Historical SQLite snapshots remain subject to provider recovery retention.
