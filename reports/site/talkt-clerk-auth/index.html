One account.
Your own agent.

Clerk sign-in now selects a private Cloudflare Durable Object for each Talkt user. Provider keys, conversations and agent storage stay with that account.

Android refreshes its Clerk session token for each cloud request. The API verifies the token before selecting the user's agent. The old shared app token no longer grants access.

The Clerk application is named Talkt and currently uses a development instance. Production Clerk keys and domain setup remain a release step.

What changed

The app has sign-in, sign-up, sign-out and OpenRouter connection controls. Device transcription works without an account. Local transcript archives are separated by account, and sign-out stops background agent work and clears Talkt notifications.

The existing shared agent was preserved. Users connect their own OpenRouter key after signing in. No old credentials or conversations are assigned automatically.

Google sign-in follow-up

A real Google login exposed a gap in the original verification. The browser returned to sign-in without an error. Clerk's server had approved an account transfer, but the callback omitted the fields its Android SDK expected.

The app now checks the server's OAuth verification before restoring the missing transfer fields. Six callback regression tests pass. The clean build completed two returning-account Google logins on the Fold and loaded the signed-in account's provider status. The first account creation also passed during diagnosis.

The original email-account isolation tests did not cover browser Google sign-in. Both first-time and returning Google login are now part of the verification instructions.
